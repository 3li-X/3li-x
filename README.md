# موقع بوشنكي للتجارة – حزمة GitHub Pages

عنوان الموقع بعد النشر: https://3li-x.github.io

## النشر
1. أنشئ مستودعاً عاماً (Public) باسم `3li-X.github.io` بالضبط.
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع، ومنها مجلد `images` وملف `.nojekyll`.
3. من Settings ثم Pages: Deploy from a branch، الفرع `main`، المجلد `/ (root)`. ثم فعّل Enforce HTTPS.
4. بعد دقيقة أو دقيقتين افتح https://3li-x.github.io

الروابط الأساسية و`sitemap.xml` و`robots.txt` مضبوطة على هذا العنوان.
عند استخدام نطاق خاص لاحقاً، استبدل `https://3li-x.github.io` بنطاقك في: `index.html` و`qarabis.html` و`wadi-althahab.html` و`sitemap.xml` و`robots.txt`، وأضف ملف `CNAME` يحتوي النطاق فقط.

## تعديل البيانات
في كل صفحة من الصفحات الثلاث ابحث عن `const CONFIG` في أسفل الملف، وعدّل: رابط واتساب، رقما الهاتفين، عنوان ودلالات فرع وادي الذهب، روابط الخرائط، والصور (ضع الصور في `images` واكتب مساراتها).
الإعداد نفسه موجود في الصفحات الثلاث، فعدّله في كل واحدة.
النص الظاهر لمحركات البحث مكتوب أيضاً داخل HTML مباشرة، وتعيد الصفحة رسمه عند الفتح. بعد تغيير كبير أرسل لي القيم الجديدة وأعيد توليد الحزمة.

## بعد النشر
- سجّل الموقع في Google Search Console وأرسل https://3li-x.github.io/sitemap.xml
- أنشئ ملفاً لكل فرع في Google Business Profile.
- استخدم اسم الفرع والعنوان والرقم بنفس الصيغة في فيسبوك وإنستغرام وخرائط Google والموقع.
